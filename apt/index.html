Install on Ubuntu / Debian

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://apt.guysinc.pub/guysinc-apt.gpg | sudo tee /etc/apt/keyrings/guysinc-apt.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/guysinc-apt.gpg] https://apt.guysinc.pub stable main" | sudo tee /etc/apt/sources.list.d/guysinc-github-desktop.list
sudo apt update && sudo apt install github-desktop

You'll get updates automatically through apt from here on.

Why this build?

🟢 Actively maintained

The long-running community fork went quiet in 2025. This one is being kept current — starting where it left off.

🔐 Signed repository

Packages are served from a GPG-signed APT repo, so apt verifies every update. No unsigned downloads.

📦 Every format

.deb, .rpm, and AppImage for x64 and ARM — pick what fits your distro.

🔑 Real sign-in

Ships with its own OAuth app, so signing in to GitHub.com just works.
